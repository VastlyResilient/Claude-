# Absolute Transportation — Partnership Deck

A luxury B2B partnership deck for **Absolute Transportation, LLC** (absolute-transportation.com),
designed to attach to outreach emails to travel agencies, cruise planners, hotels, and corporate/event teams.

- **Deliverable:** `Absolute-Transportation-Partnership-Deck.pdf` (13 pages, US Letter, ~2 MB — email-friendly)
- **Source:** `deck.html` + `assets/` (real fleet photography pulled from the live site, plus embedded Playfair Display + Jost fonts)
- **Rebuild:** `./build.sh` (renders `deck.html` via headless Chromium, then recompresses images to keep the file small)
